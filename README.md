## [Fantasy Premier League Data Analysis](https://github.com/idAhmedAli/Fantasy-Premier-League-Data-Analysis)

في هذا المشروع استخدمت بعض مكتبات لغة البايثون لأتمتة عملية استخراج البيانات من موقع فانتسي بريميرليغ و اجريت عمليات التنظيف و التترتيب قبل اجراء عملية التحليل التي تساعد في اتخاذ القرار الصحيح لتحقيق اعلى نقاط.

This project aims to assist Fantasy Premier League users in making informed decisions about selecting players who will help them achieve the highest points in the game. It utilizes Python libraries such as Selenium for web scraping and Pandas for cleaning, filtering, and handling data.

## [Simulating a Twitter (X) Database using MySQL](https://github.com/idAhmedAli/Simulating-a-Twitter-X-Database-)

هذا المشروع عبارة عن كود لمحاكاة انشاء قاعدة بيانات شبيهة لتلك الخاصة بمنصة تويتر (X)، تتضمن جداول للمستخدمين و الحسابات و التغريدات و العلاقات بين الجداول.

This code sets up a comprehensive database for a social media platform similar to Twitter (X). It includes tables for users, profiles, tweets, and follow relationships. Additionally, it provides stored procedures to facilitate account creation and managing follow relationships between users.
